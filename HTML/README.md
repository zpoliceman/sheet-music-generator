# 统一网页使用说明

网页提供访问码登录、MP3／NCM音源和TXT歌词上传、歌词预览、本人素材管理、MP3试听，以及已有吉他伴奏工程的PDF／整套JPG下载。新上传素材的整首制谱仍需通过[主项目脚本](../README.md)完成。

## 安装与启动

安装Python 3.11、默认位置的Google Chrome和微软雅黑字体；准备`ffprobe.exe`并加入`PATH`，或放到主项目`.tools/ffmpeg/任意版本/bin/`。在项目根目录的PowerShell执行：

```powershell
.\HTML\准备环境.ps1
.\HTML\启动网页.cmd
```

准备脚本只创建`HTML/.venv/`、安装锁定的网页及打印依赖，并下载和校验Cloudflare分享工具；不会向主模型环境安装包。安装过程需要联网。旧版工程的打印转换还需要已配置好的主项目环境。

本机打开[http://127.0.0.1:8768/](http://127.0.0.1:8768/)，从`HTML/runtime/app/管理员访问码.txt`复制管理员访问码登录。不要直接双击`web/index.html`，上传功能需要Python服务。

## 上传与分享

管理员点击“邀请朋友”，为每位朋友生成独立访问码，并复制当前分享网址。朋友登录后选择音源和歌词，点击“上传并保存素材”；各人的文件分别保存。MP3最长5分钟、最大80MB，TXT歌词最大256KB，支持UTF-8和GB18030编码。NCM目前保留原件并检查容器头，接收成功不代表已完成解码或制谱。

启动器通过Cloudflare临时通道提供分享地址，网址重新创建后可能变化。分享期间电脑须保持开机、联网并运行服务。双击`HTML/停止网页.cmd`停止本网页及其分享进程；日志在`HTML/runtime/logs/`。

## 下载曲谱

登录后在“曲谱下载”选择已有吉他工程，再选择PDF（Portable Document Format，便携式文档格式）或整套JPG并生成。完成后网页提供下载和分页预览；JPG按每页300 DPI（Dots Per Inch，每英寸点数）打包为ZIP压缩文件。

管理员可导出本机正常曲谱库，朋友只读取归属于自己的成品。右手编辑器中先点击“保存并生成整曲”，再下载已保存版本。导出结果另存，不覆盖原曲谱。

`portal/`处理上传及身份，`web/`保存网页界面，`printing/`生成默认打印版，`scripts/`提供运行辅助。`runtime/`中的访问码、会话、上传文件和导出数据，以及`.venv/`、`bin/`等本机目录不提交GitHub。
